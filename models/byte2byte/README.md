# Входы ветки byte2byte

Всё, из чего собирается файл, отправленный в лидерборд.

| Файл | Размер | Откуда |
|---|---|---|
| `base_submission_segmented.csv` | 3.5 МБ | предсказание базового ансамбля, берётся готовым |
| `cold_mask.npy` | 127 КБ | сегментация test из зафиксированного прогона |
| `vblock_dynamics_final.txt` | 35 МБ | 712 признаков, 750 деревьев, сид 9203 — обучается ноутбуком |
| `vblock_structured_final.txt` | 36 МБ | 1046 признаков, 750 деревьев, сид 13303 — обучается ноутбуком |

Веса в git не входят. Ноутбук кладёт их сюда после обучения и отсюда же читает при
`TRAIN_MODELS = False`. Если весов нет, берутся готовые предсказания из
`artifacts/pred_*.npy` — итоговый сабмит получается тот же.
